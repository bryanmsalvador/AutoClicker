# ⚡ AutoClicker Pro

Autoclicker com interface gráfica para Windows — sem instalação, só rodar o `.exe`.

---

## Funcionalidades

| Recurso | Detalhes |
|---|---|
| **Clique esquerdo / direito / meio** | Clica no botão do mouse escolhido |
| **Tecla do teclado** | Pressiona qualquer tecla (ex: `f`, `space`, `enter`, `f5`) |
| **Scroll Up / Down** | Rola a página |
| **Intervalo ajustável** | Horas / Minutos / Segundos / Milissegundos |
| **Repetição** | Infinito ou número fixo de cliques |
| **Janela específica** | Funciona SOMENTE quando a janela escolhida está em foco |
| **Todas as janelas** | Clica independente de qual janela está ativa |
| **Hotkey F6** | Inicia/Para sem precisar clicar no botão |

---

## Teclas especiais suportadas

`space` `enter` `tab` `esc` `shift` `ctrl` `alt`  
`backspace` `delete` `up` `down` `left` `right`  
`f1` até `f12`  
_(qualquer letra ou número também funciona: `a`, `1`, `z`, etc.)_
